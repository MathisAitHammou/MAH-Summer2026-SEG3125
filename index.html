How I Work

When trying to design a user interface, I like to start by going over the specifications and requirements of the project to see exactly what needs to be present in the design.

When that's done, I can then make a list of every key component that needs to be included in the website, filling in the blanks that the specs might've left out and making sure I don't second guess myself while implementing them.

After doing so, I then start implementing my design, following exaclty what I planned out to create a working prototype. This is done so I can then have a good look at what I have created as this really helps me make sure everything is there.

Finally, I can then use that prototype to test out the design and see if it is working as intended while also adjusting the design to make it look as sleek and user friendly as possible.
