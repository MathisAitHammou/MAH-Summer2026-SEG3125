Second Year Software Engineering Student at the University of Ottawa

I am currently a software engineering student learning how to design user interfaces in SEG3125. This portfolio showcases four projects I've built throughout the course: a service booking site, a memory game, an e-commerce platform, and a bilingual data dashboard.

How I Work

When designing a user interface, I start by going over the specifications and requirements to understand exactly what needs to be present in the design.

I then list every key component that needs to be included, filling in any gaps the specifications might have left out.

I implement the design following my plan to create a working prototype, which helps me verify everything is in place.

Finally, I test the prototype, adjust the design, and refine it to be as user-friendly as possible.
